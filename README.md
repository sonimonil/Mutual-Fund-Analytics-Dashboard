# Mutual Fund Analytics Dashboard (live)

A Power BI report on 41 Indian mutual funds, built on **live NAV data**. Every
refresh pulls the full daily NAV history that AMFI publishes, through
[api.mfapi.in](https://www.mfapi.in/). The model does not depend on a static CSV.

It answers the questions an investor actually asks:

| Page | Question |
|---|---|
| **Home** | The headline numbers, plus a chart and a table you reshape yourself: pick the metric, the breakdown and the table's columns |
| **Pulse** | What moved on the latest NAV date, and how has every fund done over 1D to 10Y? |
| **Fund** | How has this fund grown against its benchmark? How deep were its falls, and how did it do year by year? |
| **Beat the index** | How many active funds beat their benchmark index, over 1, 3 and 5 years? |
| **Risk** | What return did each fund pay for its volatility? (Sharpe, Sortino, drawdown, beta, capture ratios) |
| **Rolling** | Was the return consistent? How often did a 3-year holding beat an FD, or lose money? |
| **SIP** | What would ₹10,000 a month since 2016 be worth today, and how does that compare with an FD? |
| **Method** | Where the data comes from, how every number is computed, and the caveats |

## What the data says (NAV date 13 Nov 2026)

- **Cash won the last year.** SBI Liquid Fund returned 6.5%, and 29 of the 36
  equity funds returned less. The equity funds averaged 3.0%.
- **28 of 30 active funds beat their benchmark index over 3 years** (26/30 over
  1 year, 24/28 over 5). Treat that as **survivorship bias, not proof that active
  management works**. The list is today's *popular* funds, and funds get popular by
  doing well. Laggards that were merged or closed are not in it.
- **Axis funds hold three of the four largest 5-year shortfalls** against their
  index: Axis ELSS −3.2%/yr, Axis Midcap −1.9%, Axis Large Cap −1.3%.
- **Parag Parikh Flexi Cap had the lowest equity volatility** (9.8% over 3 years)
  and the shallowest drawdown (−11%). It captured only 56% of its index's down days.
- **A ₹10,000/month SIP from Jan 2016** in Parag Parikh Flexi Cap: ₹13.1 lakh in,
  ₹35.6 lakh today, an XIRR of 17.4%. The best SIP in the set was Quant Small Cap
  (23.8% XIRR).

## Power BI features used

- **Live web source.** Power Query calls the API once per scheme. The base URL is
  static and the scheme code goes in `Web.Contents(…, [RelativePath = …])`, which
  lets the model run on a **scheduled refresh in the Power BI service**. A
  concatenated URL would be a "dynamic data source" that the service refuses to
  refresh.
- **Power Query custom functions.** One function cleans and enriches each
  scheme's raw rows. It does as-of lookups through a forward-filled calendar list
  (O(1) per lookup), computes rolling 1/3/5-year CAGRs, tracks running peaks for
  window drawdowns, and aligns each fund with its benchmark on the same date.
- **DAX user-defined functions** (compatibility level 1702): `MF.CAGR`,
  `MF.AnnualisedVol`, `MF.StepUpAmount`, `MF.SignColour`.
- **A calculation group, `Comparison`**, with four items: Fund, Benchmark, Category
  average, and Fund vs benchmark. A single `Growth of 10K` measure draws both lines
  of the fund-vs-index chart, and the scorecard needs no benchmark copy of any
  measure.
- **Field parameters.** You can pick any of 10 metrics against any of 4 breakdowns, and a
  multi-select parameter chooses which of 15 measures appear as the Home table's columns.
- **What-if parameters**: SIP amount, start year, annual step-up, and the FD rate.
- **The `RANK` window function**, `XIRR`, **synced slicers** (fund, horizon and FD
  rate follow you across pages), a **report-page tooltip**, and **conditional
  formatting driven by measures**. Signed returns carry ▲/▼ glyphs as well as
  green/red, so sign never depends on colour alone. KPI tiles carry icon badges.
- **PBIP project format** (TMDL model + PBIR report). Everything is generated by
  Python scripts and diff-able in git.

## Verified, not just built

`scripts/fetch_snapshot.py` recomputes every return, volatility, drawdown, Sharpe
ratio, benchmark excess and SIP XIRR **independently in plain Python**.
`scripts/compare_reference.py` diffs those figures against the DAX:
**774 values, 0 mismatches** (tolerance 1e-6).

## Data and method

- **Universe.** 41 Direct-Plan Growth funds: 30 active equity funds in 7
  categories, 6 index funds, 2 balanced-advantage, 2 corporate-bond and 1 liquid
  fund. The list is in `scripts/funds.py`.
- **Cleaning** happens in Power Query on every refresh. It drops NAVs ≤ 0, keeps
  one NAV per date, and drops isolated one-day spikes, meaning a print more than
  15% from both neighbours that snaps back within 5%. Four bad prints are removed
  today; the COVID crash of 23 March 2020 is real and is kept.
- **Returns** end on each fund's latest NAV. A window starts on the last NAV on or
  before the same date N months earlier. Windows of 1 year or more are annualised
  (CAGR, actual days/365) and shorter ones are absolute, following the AMFI
  convention.
- **Benchmarks** are index funds that track each category's SEBI benchmark: Nifty
  50, Nifty 500, LargeMidcap 250, Midcap 150 and Smallcap 250. An index fund's NAV
  includes dividends, which a price index like ^NSEI does not. Only the Nifty 50
  proxy reaches back to 2013, so a comparison the proxy cannot cover is left blank.
- **Risk-free rate** is SBI Liquid Fund's *realised* return over the same window,
  not an assumed number.
- **Not investment advice.** This is an analysis of published NAVs.

## Opening it

1. Open `Mutual Fund Analytics Dashboard.pbix` in Power BI Desktop. A recent
   version is required for DAX user-defined functions.
2. Click **Refresh**. The first time, Desktop asks two one-time questions:
   - *Access Web content*: choose **Anonymous** and click **Connect**.
   - *Privacy levels*: set `https://api.mfapi.in/` to **Public** and click **Save**.
3. The refresh downloads about 132,000 NAV rows. Every later refresh picks up the
   newest NAVs.

**Publishing.** Publish to a workspace. Under *Semantic model → Settings → Data
source credentials*, set the web source to Anonymous / Public, then turn on
**scheduled refresh**. AMFI publishes NAVs every business evening, so a daily
refresh at around 10 pm IST keeps the report current.
